# Property Order

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Español](README.es-ES.md) · [Português](README.pt-BR.md) · [Русский](README.ru-RU.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Tiếng Việt](README.vi-VN.md) · [العربية](README.ar.md)

Property Order は、Obsidian のプロパティ表示でリストの値をドラッグして並べ替えたり、入力中に表示されるプロパティ名や値の候補を設定したりできるプラグインです。

## デモ

デスクトップでは、同じノート内の別のリスト形式のプロパティへ値をドラッグして移動できます。

![プロパティ間で値を移動](../assets/property-order-cross-property-drag.gif)

プロパティ間のドラッグは既定で有効です。「値の並び順」の設定で無効にできます。

## 機能

- 対応するトップレベルの YAML リスト内で値をドラッグし、順序を変更できます。
- 同じノート内の対応するリスト形式のプロパティ間で値を移動できます。この機能は既定で有効で、必要に応じて無効にできます。
- Obsidian が空の値や単一の値をリスト形式のプロパティとして扱っている場合も、安全に値を出し入れできます。文字列以外の項目は、元の YAML 表記を保った文字列に変換されます。
- プロパティごとに現在のリスト形式を保つか、角括弧形式または 1 行に 1 項目の形式を選べます。ドラッグによる変更は、1 回の取り消しで元に戻せます。
- 折り返しや右から左へのレイアウトに対応しています。対応するプロパティ領域の端でスクロールでき、ドラッグの状態変化をスクリーンリーダーに通知します。
- Obsidian のプロパティ名の候補を、上部固定・下部配置・非表示にしたり、名前順・最近使用した順・使用ノート数で並べ替えたりできます。プロパティの種類ごとにまとめることもできます。
- プロパティ値の候補には、Obsidian の順序・名前順・確定した選択回数・使用ノート数・候補を表示しない・カスタム候補を、プロパティごとに設定できます。
- カスタム候補は、上部に固定する候補・通常の候補・下部に配置する候補に分けられます。登録した値は、どのノートでもまだ使っていなくても候補として利用できます。
- 最近使用した名前の履歴と値の選択回数は、Obsidian が編集を確認してから更新されます。マウスを重ねる、候補間を移動する、キャンセルする、編集を確定しない、といった操作は記録されません。
- YAML や Obsidian の候補表示を安全に扱えない場合、ノートや元の表示には手を加えません。

## 動作要件と互換性

- Obsidian 1.12.7 以降。
- デスクトップでは直接ドラッグできます。モバイルでは、Obsidian の長押しメニューで操作を選んでからドラッグします。
- 値のドラッグは、Obsidian がテキストのリストとして認識するトップレベルの YAML プロパティに対応しています。値の候補の調整は通常、Obsidian の既存の候補を並べ替えます。カスタム候補では、同じプロパティの入力欄を通して登録済みの値を追加できます。詳しい制限は後述します。

## インストール

### コミュニティプラグインから（推奨）

Obsidian の **設定 → コミュニティプラグイン → 閲覧** を開き、**Property Order** を検索して、**インストール**、**有効化** の順に選びます。[コミュニティプラグインのページ](https://obsidian.md/plugins?id=property-order)から開くこともできます。手動インストールが必要な場合のみ、次の ZIP ファイルを使う手順に従ってください。

### 手動インストール

[最新リリース](https://github.com/ZHYX91/obsidian-property-order/releases/latest)から `property-order-<version>.zip` をダウンロードし、`Vault/.obsidian/plugins/` に展開します。ZIP には、`main.js`、`manifest.json`、`styles.css` が入った `property-order/` ディレクトリが含まれています。Obsidian を再読み込みし、コミュニティプラグインから Property Order を有効にしてください。

### アップグレード

`Vault/.obsidian/plugins/property-order/data.json` がある場合は、バックアップして保持してください。置き換えるのは `main.js`、`manifest.json`、`styles.css` だけです。`data.json` を削除するのは、プラグインの設定をすべてリセットしたい場合に限ってください。

## 使い方

1. **設定 → コミュニティプラグイン** で Property Order を有効にします。
2. トップレベルの YAML リストを持つノートを開き、Obsidian のプロパティ表示を使います。
3. デスクトップでは値を直接ドラッグします。モバイルでは値を長押しして **並べ替え** または **並べ替え・移動** を選んでから、その値をドラッグします。
4. **プロパティ名の候補** で名前の候補を設定します。必要に応じて **プロパティ値の候補** も有効にすると、既定の設定とプロパティごとのルールで Obsidian の値の候補を並べ替えられます。

**どちらの候補を設定するか。** 新しいプロパティの **名前** を入力するときは、**プロパティ名の候補** が `status` や `owner` などの上部固定・非表示・並べ替えを制御します。`status` を選んでその **値** を編集するときは、**プロパティ値の候補** が `todo` や `done` などの既存の値と、自分で登録した候補を制御します。値の候補の調整は既定では無効です。どちらの設定も、値を選択または編集するまではノートを変更しません。

**例：`status` によく使う値を登録する。** **プロパティ値の候補** を開いて **プロパティ値の候補を調整する** を有効にし、**カスタム候補** のルールカードを追加します。そのカードに `status` を追加してください。**上部に固定する候補** に `todo` を入力して **候補を登録** を選び、`doing` と `done` も同じように登録します。`status` を編集すると、入力内容に合う値が候補として表示されます。通常の並び順に含めたい候補は、隣の **↔（通常の候補に戻す）** をクリックしてください。

## 設定

対応するすべての Obsidian バージョンで、同じ 4 つの設定タブを使います。

- **一般**：表示言語と診断メッセージを設定します。画面と README は、英語、簡体字中国語、繁体字中国語、ドイツ語、フランス語、スペイン語、ブラジルポルトガル語、ロシア語、日本語、韓国語、ベトナム語、アラビア語に対応しています。**Obsidian に合わせる** を選ぶと同じ言語になり、未対応の言語の場合は英語になります。
- **値の並び順**：ドラッグ後のリスト形式、プロパティ間の移動、ドラッグの動作を設定します。値のドラッグを無効にしても、プロパティ間の移動の設定は保持されます。
- **プロパティ名の候補**：上部固定・下部配置・非表示にする名前と、名前順・最近使用した順・使用ノート数による並べ替えを設定します。**プロパティの種類ごとに候補をまとめる** を使うと、通常の候補をテキスト、リスト、数値、チェックボックス、日付、日付と時刻、タグ、自動 / 未指定に分けられます。各グループ内には選択した並び順が適用されます。
- **プロパティ値の候補**：必要に応じて有効にします。個別に設定していないプロパティには既定の表示方法が適用されます。プロパティ名を指定して、名前順、選択回数、使用ノート数、Obsidian の順序、候補を表示しない、カスタム候補を割り当てられます。
- カスタム候補には、上部に固定する候補・通常の候補・下部に配置する候補の 3 つの欄があります。値を直接登録できるため、ノートでまだ使っていない値も選べます。
- **この設定画面でのプロパティの並び順** は、ルールカードとカスタム候補の編集画面での順序だけを変えます。ノート内のプロパティや値の候補の順序は変わりません。
- プロパティ名の使用履歴は、この端末に最大 100 件保存されます。値の選択回数もこの端末だけに保存されます。どちらも `data.json` とは別に保存され、同期されず、設定から消去できます。

## 制限

- 値のドラッグは、Obsidian がテキストのリストとして表示するトップレベルの YAML プロパティに限られます。
- オブジェクトのリスト、入れ子のリスト、複数行にまたがる角括弧形式のリスト、ソースモードでの行ドラッグ、ファイル間の移動には対応していません。
- モバイルでは、Obsidian の長押しメニューで **並べ替え** または **並べ替え・移動** を選んでから値をドラッグします。編集、リストから削除、コピーなどの元の操作も使えます。
- 種類の不一致が表示されていても、Obsidian がリスト形式として明確に認識できるプロパティは操作できる場合があります。複数の値が混在して識別しにくい行では安全を優先し、末尾への追加だけを許可する場合があります。
- 登録したカスタム候補は、プロパティ表示で値を編集するときに使えます。Obsidian が候補を表示しない場合、Property Order が入力欄の横に候補を表示できます。入力欄を安全に特定できない場合でも、通常どおり手入力できます。
- 1 行に 1 項目のリストを角括弧形式に変換すると、その形式では表せないコメントや空行が失われる場合があります。
- プロパティ値をキーボードだけで直接並べ替えることは、現在できません。ポインターによるドラッグでは、スクリーンリーダーに状態を通知します。

## プライバシーとセキュリティ

Property Order はローカルで動作します。アカウントは不要で、ノートの内容をアップロードしたり、リモートサービスを呼び出したりしません。

ドラッグで変更するのは、移動に関係するプロパティだけです。結果を確認してから Obsidian に保存を依頼し、安全に扱えない構造には書き込みません。

使用ノート数で並べ替える場合は、Markdown ファイルの一覧と Obsidian にキャッシュされたプロパティ情報を使います。各ノートの本文を読み込むことはありません。プロパティ名の使用履歴と確定した値の選択回数は、現在の端末の保管庫ごとのローカルストレージに、`data.json` とは別に保存され、設定から消去できます。

## 開発

Node.js 24.19.0 と npm 11.17.0 を使います。`package-lock.json` に記録されたバージョンの依存関係をインストールしてから、リポジトリのすべてのチェックを実行してください。

```bash
npm ci
npm run check
```
