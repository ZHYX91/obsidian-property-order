# Property Order

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Español](README.es-ES.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru-RU.md) · [Tiếng Việt](README.vi-VN.md) · [العربية](README.ar.md)

Property Order를 사용하면 Obsidian의 속성 화면에서 목록 값을 드래그하고, 입력 중에 표시할 속성 이름과 값 후보를 설정할 수 있습니다. 목록 값과 입력 후보의 순서를 바꾸지만 노트 안의 속성 필드 자체를 재배치하지는 않습니다.

## 데모

데스크톱에서는 같은 노트의 다른 목록 속성으로 값을 드래그해 옮길 수 있습니다.

![속성 사이로 값 이동](../assets/property-order-cross-property-drag.gif)

속성 간 드래그는 기본으로 켜져 있으며, '속성 값 순서' 설정에서 끌 수 있습니다.

## 기능

- 지원되는 최상위 YAML 목록 안에서 값을 드래그해 순서를 바꿉니다.
- 같은 노트에서 지원되는 목록 속성 사이로 값을 옮깁니다. 속성 간 이동은 기본으로 켜져 있으며 필요에 따라 끌 수 있습니다.
- Obsidian이 빈 값이나 단일 값을 목록 속성으로 취급하는 경우에도 값을 안전하게 넣거나 뺄 수 있습니다. 텍스트가 아닌 항목은 원래 YAML 표기를 유지한 텍스트로 변환됩니다.
- 속성마다 현재 목록 형식을 유지하거나 대괄호 목록 또는 한 줄에 한 항목 형식을 선택할 수 있습니다. 드래그로 변경한 내용은 한 번의 실행 취소로 되돌릴 수 있습니다.
- 줄바꿈된 배치와 오른쪽에서 왼쪽으로 쓰는 배치를 지원합니다. 지원되는 속성 영역의 가장자리에서 스크롤할 수 있으며, 드래그 상태 변화를 화면 읽기 프로그램에 알립니다.
- Obsidian의 속성 이름 후보를 상단 고정, 하단 배치, 숨김으로 설정하거나 이름순, 최근 사용순, 노트 수로 정렬합니다. 속성 유형별로 묶을 수도 있습니다.
- 속성 값 후보에는 Obsidian 순서, 이름순, 확정된 선택 횟수, 노트 수, 후보 표시 안 함, 사용자 지정 후보를 속성별로 지정할 수 있습니다.
- 사용자 지정 후보를 상단 고정, 일반, 하단 배치 영역으로 나눌 수 있습니다. 미리 등록한 값은 아직 어떤 노트에서도 사용하지 않았더라도 계속 선택할 수 있습니다.
- 최근 속성 이름 기록과 값 선택 횟수는 Obsidian이 편집 내용을 확인한 뒤에만 바뀝니다. 마우스를 올리거나 후보를 탐색하거나 취소한 경우, 또는 편집을 확정하지 않은 경우에는 기록하지 않습니다.
- YAML이나 Obsidian의 후보 화면을 안전하게 처리할 수 없으면 노트나 원래 화면을 변경하지 않습니다.

## 요구 사항 및 호환성

- Obsidian 1.12.7 이상.
- 데스크톱에서는 바로 드래그할 수 있습니다. 모바일에서는 Obsidian의 길게 누르기 메뉴에서 작업을 선택한 뒤 드래그합니다.
- 값 드래그는 Obsidian이 텍스트 목록으로 인식하는 최상위 YAML 속성을 지원합니다. 값 후보 조정은 보통 Obsidian의 기존 후보를 재정렬합니다. 사용자 지정 후보를 사용하면 같은 속성 입력란을 통해 미리 등록한 값을 추가할 수도 있습니다. 자세한 범위는 아래 제한 사항을 참고하세요.

## 설치

### 커뮤니티 플러그인에서 설치하기 (권장)

Obsidian의 **설정 → 커뮤니티 플러그인 → 탐색**에서 **Property Order**를 검색하고 **설치**, **활성화**를 차례로 선택하세요. [커뮤니티 플러그인 페이지](https://obsidian.md/plugins?id=property-order)를 열어 설치할 수도 있습니다. 수동 설치가 필요한 경우에만 아래 ZIP 설치 방법을 사용하세요.

### 수동 설치

[최신 릴리스](https://github.com/ZHYX91/obsidian-property-order/releases/latest)에서 `property-order-<version>.zip`을 다운로드하고 `Vault/.obsidian/plugins/`에 압축을 푸세요. 압축 파일에는 `main.js`, `manifest.json`, `styles.css`가 들어 있는 `property-order/` 폴더가 포함되어 있습니다. Obsidian을 다시 불러온 뒤 커뮤니티 플러그인에서 Property Order를 활성화하세요.

### 업그레이드

`Vault/.obsidian/plugins/property-order/data.json`이 있으면 백업하고 보존하세요. `main.js`, `manifest.json`, `styles.css`만 교체합니다. 플러그인 설정을 모두 초기화하려는 경우에만 `data.json`을 삭제하세요.

## 사용법

1. **설정 → 커뮤니티 플러그인**에서 Property Order를 활성화합니다.
2. 최상위 YAML 목록 속성이 있는 노트를 열고 Obsidian의 속성 화면을 사용합니다.
3. 데스크톱에서는 값을 바로 드래그합니다. 모바일에서는 값을 길게 누르고 **순서 변경** 또는 **순서 변경 또는 이동**을 선택한 뒤 해당 값을 드래그합니다.
4. **속성 이름 후보**에서 이름 후보를 설정합니다. 필요하면 **속성 값 후보**도 켜서 기본 설정과 속성별 규칙에 따라 Obsidian의 기존 값 후보를 정렬하세요.


**드래그 전 주의:** 지원되는 텍스트 목록을 변경하면 YAML의 문자열이 아닌 값이 문자열로 바뀔 수 있습니다. 예를 들어 `true`는 `"true"`로, `123`은 `"123"`으로 바뀝니다. 순서뿐 아니라 값의 유형도 달라질 수 있으니 숫자나 참/거짓 값이 중요하다면 결과를 확인하세요.

**모바일:** Obsidian 기본 길게 누르기 메뉴에 **순서 변경** 또는 **순서 변경 또는 이동**이 표시될 때만 드래그를 시작할 수 있습니다. 메뉴를 확장할 수 없는 환경에서는 비슷한 메뉴를 따로 만들지 않으며 기본 편집은 계속 가능합니다.

**어떤 후보 설정을 사용하나요?** 새 속성을 추가하며 **이름**을 입력할 때는 **속성 이름 후보**가 `status`, `owner` 같은 이름의 고정, 숨김, 정렬을 제어합니다. `status`를 선택하고 **값**을 편집할 때는 **속성 값 후보**가 `todo`, `done` 같은 기존 후보와 직접 등록한 후보를 제어합니다. 속성 값 후보 조정은 기본으로 꺼져 있습니다. 두 설정 모두 값을 선택하거나 편집하기 전에는 노트를 변경하지 않습니다.

**예: `status`에서 자주 쓸 값 등록하기.** **속성 값 후보**를 열어 **속성 값 후보 조정**을 켜고 **사용자 지정 후보** 규칙 카드를 추가하세요. 그 카드에 `status`를 추가합니다. **상단 고정 후보**에서 `todo`를 입력하고 **후보 값 등록**을 선택하세요. `doing`, `done`도 같은 방법으로 등록합니다. `status`를 편집하면 입력 내용과 일치하는 값이 후보로 표시됩니다. 등록한 값을 일반 정렬 순서에 포함하려면 옆의 **↔ (일반 후보로 이동)**을 클릭하세요.

## 설정

지원되는 모든 Obsidian 버전에서 같은 네 개의 설정 탭을 사용합니다.

- **일반**: 플러그인 언어와 선택적 진단 메시지를 설정합니다. 화면과 README는 영어, 중국어 간체, 중국어 번체, 독일어, 프랑스어, 스페인어, 브라질 포르투갈어, 러시아어, 일본어, 한국어, 베트남어, 아랍어를 지원합니다. **Obsidian 설정 따르기**를 선택하면 같은 언어를 사용하며, 지원하지 않는 언어라면 영어로 표시합니다.
- **속성 값 순서**: 드래그 후 목록 형식, 속성 간 이동, 드래그 동작을 설정합니다. 값 드래그를 꺼도 별도의 속성 간 이동 설정은 유지됩니다. 한 줄에 한 항목인 목록을 대괄호 형식으로 강제 변환하면 주석이나 빈 줄이 사라질 수 있습니다. 필요하면 원래 형식을 유지하세요.
- **속성 이름 후보**: 상단 고정, 하단 배치, 숨길 속성 이름과 이름순, 최근 사용순, 노트 수 정렬을 설정합니다. **속성 유형별로 후보 묶기**를 사용하면 일반 후보를 텍스트, 목록, 숫자, 체크박스, 날짜, 날짜 및 시간, 태그, 자동 / 미지정으로 나눕니다. 각 그룹 안에는 선택한 정렬 순서가 적용됩니다.
- **속성 값 후보**: 필요할 때 켜는 기능입니다. 개별 지정이 없는 속성은 기본 표시 방식을 사용합니다. 속성 이름을 지정해 이름순, 선택 횟수, 노트 수, Obsidian 순서, 후보 표시 안 함, 사용자 지정 후보 중 하나를 설정할 수 있습니다.
- 사용자 지정 후보 규칙에는 상단 고정, 일반, 하단 배치의 세 영역이 있습니다. 값을 직접 등록할 수 있어 노트에 아직 없는 값도 선택할 수 있습니다.
- **이 설정 화면의 속성 순서**는 규칙 카드와 사용자 지정 편집 화면의 속성 순서만 바꿉니다. 노트 안의 속성이나 값 후보의 순서는 바꾸지 않습니다.
- 최근 속성 이름 기록은 현재 기기에 최대 100개까지 저장됩니다. 선택 횟수도 현재 기기에만 저장됩니다. 둘 다 `data.json`과 별개이며 동기화되지 않고, 설정에서 지울 수 있습니다.

## 제한 사항

- frontmatter는 일반적인 최상위 속성 행으로 작성해야 합니다. YAML 전체를 `{ ... }`로 감싼 형식에서는 드래그할 수 없습니다.
- 값 드래그는 Obsidian이 텍스트 목록으로 표시하는 최상위 YAML 속성에서만 작동합니다.
- 객체 목록, 중첩 목록, 여러 줄에 걸친 대괄호 목록, 소스 모드의 줄 드래그, 파일 간 이동은 지원하지 않습니다.
- 모바일에서는 Obsidian의 길게 누르기 메뉴에서 **순서 변경** 또는 **순서 변경 또는 이동**을 선택한 뒤 값을 드래그해야 합니다. 편집, 목록에서 제거, 복사 같은 기본 작업은 계속 사용할 수 있습니다.
- 유형 불일치가 표시되는 속성도 Obsidian이 목록 속성으로 명확하게 인식하면 사용할 수 있습니다. 여러 값이 섞여 개별 값을 식별하기 어려운 행에서는 안전을 우선하며, 끝에 값을 추가하는 것만 허용할 수 있습니다.
- 등록한 사용자 지정 후보는 속성 화면에서 값을 편집할 때만 적용됩니다. Obsidian이 후보 팝업을 띄우지 않으면 Property Order가 입력란 옆에 후보를 표시할 수 있습니다. 입력란을 안전하게 식별할 수 없는 경우에도 직접 입력은 가능합니다.
- 한 줄에 한 항목인 목록을 대괄호 목록으로 바꾸면, 대괄호 형식으로 표현할 수 없는 주석이나 빈 줄이 사라질 수 있습니다.
- 현재는 키보드만으로 속성 값의 순서를 직접 바꿀 수 없습니다. 포인터로 드래그할 때는 화면 읽기 프로그램에 상태를 알립니다.

## 개인정보 보호 및 보안

Property Order는 로컬에서 작동합니다. 계정을 요구하거나 노트 내용을 업로드하거나 원격 서비스를 호출하지 않습니다.

드래그는 이동에 관련된 속성만 변경합니다. 플러그인은 결과를 확인한 뒤 Obsidian에 노트 저장을 요청합니다. 안전하게 처리할 수 없는 구조에는 쓰지 않습니다.

노트 수로 정렬할 때는 Markdown 파일 목록과 Obsidian에 캐시된 속성 정보를 사용하며, 각 노트의 본문을 읽지 않습니다. 최근 속성 이름 기록과 확정된 속성 값 선택 횟수는 현재 기기의 보관함별 로컬 저장소에 `data.json`과 별도로 저장되며, 설정에서 지울 수 있습니다.
