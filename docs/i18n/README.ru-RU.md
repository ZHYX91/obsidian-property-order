# Property Order

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Español](README.es-ES.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru-RU.md) · [Tiếng Việt](README.vi-VN.md) · [العربية](README.ar.md)

Property Order позволяет менять порядок значений списков в панели «Свойства» Obsidian перетаскиванием или через палитру команд и выбирать, какие имена и значения свойств предлагаются при вводе. Плагин меняет порядок значений списков и подсказок при вводе, но не переставляет сами поля свойств заметки.

## Демонстрация

На компьютере перетащите элемент из одного свойства типа «Список» в другое в той же заметке:

![Перемещение значения между свойствами](../assets/property-order-cross-property-drag.gif)

Перетаскивание между свойствами включено по умолчанию. Его можно отключить в разделе **Порядок значений**.

## Возможности

- Меняйте порядок значений поддерживаемого списка YAML верхнего уровня перетаскиванием или через палитру команд.
- Перемещайте значения между поддерживаемыми свойствами типа «Список» в одной заметке. Перетаскивание между свойствами включено по умолчанию, но его можно отключить.
- Если Obsidian представляет пустое или одиночное значение как свойство типа «Список», Property Order также позволяет безопасно перемещать значения в это свойство или из него. Нетекстовые элементы преобразуются в текст с сохранением исходного написания в YAML.
- Сохраняйте текущий формат списка каждого свойства или выбирайте списки в квадратных скобках либо по одному элементу на строку. Каждая успешная перестановка или перемещение создаёт одно изменение, которое можно отменить одним действием.
- Перетаскивание работает при переносе элементов на новые строки в интерфейсе и при направлении справа налево (RTL). Поддерживаемые области панели «Свойства» прокручиваются при приближении указателя к краю, а изменения состояния перетаскивания озвучиваются программами экранного доступа.
- Настраивайте встроенные подсказки имён свойств: закрепляйте, перемещайте в конец, скрывайте, сортируйте по имени, недавнему использованию или числу заметок. При необходимости доступна группировка по типу свойства.
- По желанию настройте подсказки значений для каждого свойства: порядок Obsidian, сортировка по имени, частота подтверждённого выбора, число заметок, отсутствие подсказок или свои варианты.
- Свои варианты можно закреплять, оставлять в обычном разделе или помещать в конец. Явно заданные варианты остаются доступны, даже если ни одна заметка пока их не использует.
- История недавних имён и счётчики выбора значений меняются только после того, как Obsidian подтвердит изменение. Наведение указателя, перемещение по вариантам, отмена или неподтверждённое редактирование не учитываются.
- Если Property Order не может безопасно обработать YAML или интерфейс подсказок Obsidian, заметка или встроенный интерфейс остаются без изменений.

## Требования и совместимость

- Obsidian 1.12.7 или новее.
- На компьютере значения можно перетаскивать сразу. На мобильном устройстве перед перетаскиванием нужно выбрать отдельное действие во встроенном меню Obsidian, которое открывается долгим нажатием.
- Перетаскивание значений работает только со свойствами YAML верхнего уровня, которые Obsidian определяет как текстовые списки. Настройка подсказок значений обычно меняет порядок вариантов Obsidian; режим со своими вариантами также может предлагать явно заданные значения в том же редакторе свойств. Подробные ограничения приведены ниже.

## Установка

### Плагины сообщества — рекомендуемый способ

В Obsidian откройте **Настройки → Плагины сообщества → Просмотр**, найдите **Property Order**, затем нажмите **Установить** и **Включить**. Можно также открыть [страницу плагина в каталоге сообщества](https://obsidian.md/plugins?id=property-order). Инструкции для ZIP ниже нужны только для ручной установки.

### Ручная установка

Скачайте `property-order-<version>.zip` со страницы [последнего выпуска](https://github.com/ZHYX91/obsidian-property-order/releases/latest) и распакуйте его в `Vault/.obsidian/plugins/`. Архив содержит папку `property-order/` с файлами `main.js`, `manifest.json` и `styles.css`. Перезапустите Obsidian, затем включите Property Order в разделе «Плагины сообщества».

### Обновление

Если файл `Vault/.obsidian/plugins/property-order/data.json` существует, сделайте его резервную копию и сохраните сам файл. Заменяйте только `main.js`, `manifest.json` и `styles.css`; удаляйте `data.json`, только если намеренно хотите сбросить все настройки плагина.

## Использование

1. Включите Property Order в разделе **Настройки → Плагины сообщества**.
2. Откройте заметку со списками YAML верхнего уровня в панели «Свойства» Obsidian.
3. На компьютере перетащите значение сразу. На мобильном устройстве нажмите и удерживайте значение, выберите **Изменить порядок** или **Изменить порядок или переместить**, затем перетащите это значение.
4. Настройте **Подсказки имён** для вариантов имён свойств. При желании включите **Подсказки значений**, чтобы упорядочить существующие варианты значений Obsidian с помощью общих настроек и правил для отдельных свойств.

**С клавиатуры:** Откройте палитру команд Obsidian и выполните **Property Order: Изменить порядок значений свойств**. Выберите исходное свойство и значение, затем **Вверх**, **Вниз** или **Переместить в свойство**. При переносе в другое свойство значение добавляется в конец. Команда работает и при отключённом перетаскивании; настройка перетаскивания между свойствами относится только к указателю. До начала перемещения **Escape** или **Отмена** оставляет заметку без изменений. После запуска дождитесь завершения; затем изменение можно отменить в редакторе. Сочетание клавиш по умолчанию не назначено.

**Перед изменением порядка:** При перестановке или переносе значений в поддерживаемом текстовом списке нетекстовые значения YAML могут стать строками: `true` превращается в `"true"`, а `123` — в `"123"`. Может измениться тип данных; проверьте результат, если типы важны.

**На телефоне:** перетаскивание доступно, только когда исходное меню Obsidian по долгому нажатию показывает **Изменить порядок** или **Изменить порядок или переместить**. Если расширение меню недоступно, плагин не подменяет его своим, а обычное редактирование остаётся возможным.

**Какой раздел подсказок выбрать?** Когда вы добавляете новое свойство и вводите его **имя**, раздел **Подсказки имён** управляет закреплением, скрытием и порядком имён, например `status` или `owner`. После выбора `status`, когда вы редактируете его **значение**, раздел **Подсказки значений** управляет существующими вариантами, например `todo` или `done`, и позволяет добавить собственные заданные варианты. Подсказки значений по умолчанию отключены. Изменение настроек подсказок не редактирует заметки. Выбор или редактирование свойства в Obsidian может изменить заметку.

**Пример: добавление часто используемых значений для `status`.** Откройте **Подсказки значений**, включите **Настроить подсказки значений свойств** и добавьте карточку правил **Свои варианты**. Добавьте в эту карточку свойство `status`. В разделе **Закреплённые варианты** введите `todo` и нажмите **Добавить свой вариант**; повторите для `doing` и `done`. При редактировании `status` эти значения будут предлагаться с учётом введённого текста. Чтобы включить заданный вариант в обычную сортировку, нажмите **↔ (Переместить в обычные)** рядом с ним.

## Настройки

Во всех поддерживаемых версиях Obsidian используются одни и те же четыре вкладки настроек:

- Вкладка **Общие** позволяет выбрать язык плагина и включить дополнительные диагностические уведомления. Интерфейс и README доступны на английском, упрощённом китайском, традиционном китайском, немецком, французском, испанском, бразильском португальском, русском, японском, корейском, вьетнамском и арабском языках. Настройка **Как в Obsidian** выбирает соответствующий язык, а если он недоступен — английский.
- **Порядок значений** управляет форматом списков после перестановки и перетаскиванием внутри свойства или между свойствами. Отключение перетаскивания значений не сбрасывает отдельную настройку перетаскивания между свойствами. Принудительное преобразование списка с отдельной строкой для каждого элемента в список в скобках может убрать комментарии и пустые строки. Если они нужны, сохраняйте исходный формат. Раскройте **Примеры формата** рядом с **Формат списка после перестановки**, чтобы перед выбором сравнить один исходный список во всех трёх форматах.
- На вкладке **Подсказки имён** можно настроить закреплённые, скрытые и помещённые в конец имена свойств, а также выбрать сортировку **По имени**, **Недавно использованные** или **Число заметок со свойством**. Дополнительная группировка по типу свойства распределяет обычные варианты по группам **Текст**, **Список**, **Число**, **Флажок**, **Дата**, **Дата и время**, **Теги** и **Автоматически / не задан**. Выбранная сортировка продолжает действовать внутри каждой группы.
- **Подсказки значений** включаются отдельно. Свойства без своего правила используют режим по умолчанию. Для свойств, указанных по точному имени, можно выбрать **По имени**, **Частота выбора**, **Число заметок со значением**, **Порядок Obsidian**, **Без подсказок** или **Свои варианты**.
- Правила своих вариантов содержат разделы **Закреплённые варианты**, **Обычные варианты** и **Варианты в конце**. Заданные значения можно вводить напрямую, поэтому они доступны для выбора ещё до первого использования в заметке.
- **Порядок свойств в этих настройках** меняет только порядок свойств в карточках правил и редакторе своих вариантов. Порядок свойств в заметках и подсказок их значений не меняется.
- История недавних имён свойств ограничена 100 именами на текущем устройстве. Счётчики частоты выбора также хранятся только на устройстве. Оба вида данных находятся отдельно от `data.json`, не синхронизируются и могут быть очищены в настройках.

## Ограничения

- Frontmatter должен состоять из обычных строк свойств верхнего уровня. Перетаскивание не поддерживается, если весь документ YAML заключён в `{ ... }`.
- Перетаскивание значений работает только со свойствами YAML верхнего уровня, которые Obsidian отображает как текстовые списки.
- Списки объектов, вложенные списки, списки в квадратных скобках на нескольких строках, перетаскивание строк в режиме исходного кода и перемещение между файлами не поддерживаются.
- На мобильном устройстве сначала выберите **Изменить порядок** или **Изменить порядок или переместить** во встроенном меню Obsidian по долгому нажатию, затем перетащите значение. Стандартные действия, такие как «Изменить», «Удалить из списка» и «Копировать», остаются доступны.
- Некоторые строки с несовпадением типа могут участвовать в перетаскивании, если Obsidian явно определяет их как свойства типа «Список». Строки с неоднозначной смесью значений обрабатываются осторожно и могут позволять только добавление значения в конец.
- Собственные заданные варианты применяются только при редактировании значений в панели «Свойства». Если Obsidian не показывает всплывающее меню подсказок, Property Order может показать заданные варианты рядом с полем ввода. Если поле нельзя безопасно определить, обычный ввод остаётся доступен.
- При преобразовании списков с дефисами в списки в квадратных скобках могут быть потеряны комментарии или пустые строки, которые нельзя представить в таком формате.
- Команде нужен видимый поддерживаемый раздел «Свойства» в активной панели Markdown. Если файл или значения изменились при открытом диалоге, откройте команду заново.

## Конфиденциальность и безопасность

Property Order работает локально. Ему не нужна учётная запись; он не загружает содержимое заметок на серверы и не обращается к удалённым сервисам.

Перестановка или перемещение значений меняет только участвующие в операции свойства. Плагин проверяет результат, прежде чем попросить Obsidian сохранить заметку. Структуры, которые нельзя безопасно обработать, не перезаписываются.

Для сортировки по числу заметок Property Order перебирает файлы Markdown и читает кэшированные метаданные YAML; читать текст каждой заметки не требуется. История недавних имён свойств и счётчики подтверждённого выбора значений хранятся только в локальном хранилище Obsidian для текущего хранилища заметок на текущем устройстве, отдельно от `data.json`. Их можно очистить в настройках.

## Разработка

Используйте Node.js 24.19.0 и npm 11.17.0. Установите версии зависимостей, указанные в `package-lock.json`, затем выполните все проверки репозитория:

```bash
npm ci
npm run check
```
