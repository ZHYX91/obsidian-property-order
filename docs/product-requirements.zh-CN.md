# Property Order 产品需求

本文描述 Property Order 的当前产品边界。英文版用于同步阅读；若实现、测试或翻译与本文冲突，以本文为准。

## 产品目标

Property Order 只增强 Obsidian Properties 的两类顺序：

1. 在当前笔记的顶层 YAML 列表属性中重排值；
2. 按用户规则重排和过滤原生属性键候选。

插件必须保持局部、可撤销和 fail-safe：不能识别宿主 DOM 时保留 Obsidian 原生行为；不能安全解析或验证 frontmatter 时不写入笔记。

## 属性值顺序

- 支持由 Obsidian Properties 渲染为 pill 的顶层 flow list 与 block list。
- 支持同属性重排；启用跨属性拖拽后，支持同一 leaf、同一文件内受支持属性之间移动。
- 以 Obsidian 原生 Properties UI 的列表类型为准：正常多值编辑器以及同时带原生列表图标和类型不匹配警告的属性均可参与。YAML 中的空值、`[]` 或单个受支持标量都作为逻辑文本列表，标量既可拖出也可接收拖入值；混合数组被宿主合并成单字段时不得猜测 source 元素，只有其可读、无歧义的显示与当前 YAML 完全一致时才允许作为 append target。一次成功的同属性重排规范化该属性全部元素；一次成功的跨属性移动同时规范化 source 和 target 全部元素。number、boolean 和列表内 null 按原始 token 文本用双引号转成字符串，已有字符串及其可保留引号不变；对象、嵌套结构和多行值不得自动转换。
- 桌面鼠标移动达到阈值后开始拖拽；桌面应用收到的 touch/pen 输入在长按后开始拖拽。
- 移动端通过原生属性值菜单把一个 pill 置为 15 秒单次待拖动状态；下一次在同一 pill 上 touch/pen 移动达到较小阈值后直接开始拖拽，无需再次长按。点击其他位置、Escape、超时、插件卸载或 DOM 失效都会取消待拖动状态。
- 写回格式为 `preserve`、`flow` 或 `block`；同属性与跨属性操作都把所选格式应用于所有受影响属性。所有 change 都以同一份原始文本为坐标基底，每次成功拖拽只使用一次经核对的公开 editor transaction，并只形成一个撤销步骤。只有 buffer 精确匹配规划结果后才能安排保存和刷新 Properties；不得使用原生属性 setter、Vault 直写、手工搬动 pill 或自动回滚来制造或恢复结果。文本不变属于失败，部分应用或其他结果属于 divergence；noop、取消和失败不得借机格式化。
- 文件、leaf、源/目标内容或 DOM 身份在事务期间变化时取消，不得写入其他文件或覆盖较新内容。
- 拖入同一 pane 内具有原生非列表证据且由标量存储形态佐证的属性时，目标显示拒绝态且不显示插入指示器；只有在该目标上松手才显示本地化 Notice，单纯经过时不提示；无法判定的宿主属性行静默取消，不得误标为非列表。
- 冲突、非法结构或不支持结构必须给出诊断并保持磁盘内容不变。

## 属性键候选

- 支持置顶、置底、隐藏通配规则、按名称排序和按使用次数排序。
- 名称排序依次处理数字、拉丁字母、按拼音排列的中文和其他字符；usage 平局使用同一名称比较器。
- 设置页与原生候选菜单必须共享同一排序语义。
- 键盘导航按最终可见 DOM 顺序处理方向键、Home/End、PageUp/PageDown、macOS/iOS Ctrl+P/N 和 Enter。
- 全部候选隐藏时不得提交隐藏项；焦点离开属性名编辑器后不再接管键盘。
- 无法识别 Properties 菜单或同步宿主选择状态时恢复原生顺序、可见性和交互。

## 设置

- 设置使用版本化 schema；未知或非法值归一化，旧版本逐步迁移。
- General、Value drag、Key order 三个页签保留即时生效语义。
- 设置保存失败时保留内存状态，显示本地化 Notice、可访问的未保存提示和重试入口。
- 跨属性拖拽默认开启并可独立关闭；属性键候选增强也可独立关闭并完整恢复宿主状态。

## 明确非目标与限制

- 不支持嵌套列表、对象列表、多行 flow sequence、源码模式拖拽或跨文件移动。
- 强制把 block list 转成 flow list 时，允许丢弃只有 block 形式能表达的项目注释和空行。
- 移动端在 Obsidian 原生“编辑 / 从列表中移除 / 复制”菜单中追加重排操作，不替换原生菜单；无法取得宿主共享菜单时不做修改并保留原生行为。
- 属性值重排只支持指针输入；不提供键盘直接重排命令或屏幕阅读器拖拽 live-region 播报。
- 插件不会只为恢复磁盘特定换行而在 Obsidian editor transaction 后追加一次不可撤销的 Vault 写入。
- 属性键候选增强依赖可识别的公开 DOM 形态；宿主结构变化时以 fail open 为正确结果。
- 插件只处理 Obsidian 实际暴露为 Properties 的笔记；宿主不呈现 Properties 的 CR-only 文档不承诺真实 UI 写回。
