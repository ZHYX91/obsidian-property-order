# Obsidian 插件共同界面规范

这份规范供 Number Suite、Property Order、Folder Nodes、Link Integrity、Chrono Notes、Structural Tables 和 DocWen Assistant 的维护者使用。各插件的 UX 规范定义其领域操作。共同规范定义用户切换插件时可以依赖的交互和验收方法。

## 设置页签与外观

在 Obsidian 1.13 及以上版本，全局设置搜索可以按插件名打开设置页。单个设置项的索引来自 `getSettingDefinitions()`。只要返回非空列表，Obsidian 就会接管页面渲染并跳过 `display()`。由插件绘制顶部标签时，保持定义为空或省略该方法。[Obsidian 迁移指南](https://docs.obsidian.md/plugins/guides/migrate-declarative-settings)

- 一级页签保持单行。选中项使用主题强调色的 2px 下划线和半粗体。普通标签、悬停、边框、分组间距和卡片圆角沿用 Obsidian 主题变量。普通文本、危险提示和可点击操作各用对应的主题颜色。
- 将标签自然占用的宽度与整行可用宽度比较。箭头只在相应方向仍有内容时占位。点击箭头只滚动标签；箭头到尽头时，键盘焦点移到仍可用的箭头，或在全部标签可见时回到选中项。浏览器的整数滚动位置和小数像素标签边界可能相差 1 CSS px。
- 每组只有一个可用 Tab 键到达的页签。左右键按界面实际文字方向移动，Home 和 End 到达两端。上下键保留页面滚动。可访问名称和 tab、`tablist`、`tabpanel` 的关联随显示状态更新。重新打开设置，应看得到选中项；再次激活已选页签时，保留当前页面、草稿和滚动位置。被动刷新应保留外部焦点。
- 桌面设置页签的最小高度为 34 CSS px。粗指针上的页签和翻页箭头在两个方向上均至少为 44 CSS px，包括短译名，以及所有页签都放得下的情况。正文中的字形、表格和密集数据单元按各自语义布局。键盘焦点框应能在容器边缘看清，选中状态、焦点和错误还应有形状、线条或文字提示。

## 面板、对话框与操作反馈

- 设置面板和侧栏按实际可用宽度换行或调整列数。在宽桌面中缩窄面板也应生效。正文挂在页面顶层的对话框应根据自己的内容宽度排版。长属性名、路径和翻译不能挤掉输入框、操作或候选文字。
- 拖动、悬停或长按承载的主要操作应有可发现的触屏或键盘入口。重绘后保留有效的草稿、选中项和用户正在操作的控件。添加重复行后聚焦新行，删除后聚焦相邻行或添加按钮；关闭弹窗时，仍在原流程内的焦点回到触发处。
- 普通设置改值时保留原控件。语言切换或联动选项需要重绘时，按设置的稳定标识恢复焦点和滚动位置，用户已离开时保留其新焦点。
- 分别呈现加载中、空结果、过期、成功和失败中对当前操作适用的状态。错误和重试入口应能通过键盘到达。文件、笔记或选择在异步操作期间变化时，反馈仍要指明原目标。涉及写入时，预览和执行使用同一目标及相应版本。
- 窄栏或大字号下，错误详情和重试操作可以分行。展开长错误路径后，状态文字仍可读，重试保持在本面板内。
- 保留产品的领域操作。Number Suite 的计算编号与源编号要能区分；Property Order 的属性值可以通过键盘重排；Folder Nodes 的节点图保留直接操控；Link Integrity 的诊断绑定来源；Chrono Notes 的日期选择独立于焦点；Structural Tables 的预览对应实际表格操作；DocWen Assistant 的连接、校对和导出反馈各有明确作用对象。

## 回归验收

| 操作场景 | 可观察的通过条件 |
| --- | --- |
| 宽桌面中的窄面板或对话框 | 固定窗口尺寸，单独收窄并再放宽组件。输入、标签、按钮可见可用，内容没有非预期的水平滚动。 |
| 页签全部可见、局部裁切和两端 | 实测布局。翻到两端时隐藏对应箭头并回收位置，活动页面不变。窗口放宽后两箭头消失。 |
| 精细指针、粗指针、LTR、RTL | 同时测试长短译名。测量实际点击矩形。用真实键盘事件检查焦点、选中项、翻页和重新打开。 |
| 主题与辅助显示模式 | 在暗色、浅色和强制颜色中检查活动与焦点仍可辨认。出现滚动裁切或绘制顺序问题时检查实际画面。 |
| 编辑、刷新与失败 | 在输入未完成、列表增删、目标切换、保存或读取失败后，检查用户输入、焦点、目标和重试结果。 |
| 用键盘改值及切换语言 | 切换开关并改选语言或联动下拉项，检查当前设置和滚动位置。另用长译文、大字号和窄栏展开错误详情，确认重试按钮可见且可操作。 |
| 在另一个 Obsidian 窗口打开设置或对话框 | 在控件所属文档中查找焦点和标签。重绘或切换语言后，从无障碍树读取按钮名称，能找到屏幕上显示的按钮文字，也能获取操作说明及禁用原因。 |
| 在分页边界删除有焦点的行 | 焦点移到逻辑上相邻项的可用操作，包括删除最后一页唯一一项。如果分段已空，且有添加或编辑控件，焦点回到该控件。用户已经离开时保留其新焦点。 |
| 写入期间关闭通知 | 关闭操作只收起该通知。如果另有取消操作，分别验证写入提交前后的反馈。等待期间重复激活不能再次提交。失败后说明能否安全重试，或结果是否已生成。 |

几何、滚动和绘制使用真实浏览器验证。读写与宿主交互按插件的临时 Vault 验收流程验证。浏览器触摸模拟、Obsidian 桌面以及实际移动设备的结果分别记录。
